NeuralCore 블록별 동적 전력

기존 Burst·real1·real2·real3의 3개 구조, 총 12개 결과를 정리했다.
단위: mW. 실제 보드 배치·배선 DCP와 입력별 SAIF를 사용한 전력 추정값.
Event-driven은 SAIF의 클럭 전달 횟수를 반영한 평균 클럭 모델을 사용한다.
각 블록 값에는 Vivado가 해당 계층에 배분한 clock·signal·logic·memory 등의 동적 전력이 포함된다.
Core의 직접 하위 블록을 분할했으며, Control / other는 WindowController·SFEClockControl과 상위 계층의 잔여 전력이다.
원그래프의 비율은 각 구조의 Core dynamic 합계를 100%로 계산한다. 중앙 숫자는 절대 전력이다.

해석
SFE 절감 이후에는 SD와 버퍼·FIFO의 전력이 Core 전체에서 큰 비중을 차지한다.
따라서 SFE의 감소율과 Core 전체의 감소율은 각각 구분해서 읽는다.
